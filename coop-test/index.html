🌾 Coop Module Test Harness

Staging only — walks through the full savings + loan lifecycle by clicking buttons, not curl. Values auto-fill between steps where possible.
1. Admin Login
Your normal SUPER_ADMIN username + password + authenticator code.
2. Log In Two Test Members (Borrower + Guarantor)
Uses your DEMO_OTP code — same one used for any test login. Any phone number works.
3. Activate Both as Cooperative Members
Admin action — pre-provisions them into the test society.
4. Configure Society Dues
Society-level, not per-member — sets what everyone owes and how often. Without this, the dues section stays correctly hidden (nothing to show).
5. Create a Savings Plan for the Borrower
6. Provision a Real Flutterwave Account (optional, needs real keys)
Tests authentication + the provisioning endpoint against Flutterwave's real sandbox. Uses a test BVN — Flutterwave docs suggest any 11-digit value works in test mode, but this hasn't been confirmed against your specific account yet.
5b. Simulate a Payment (tests the webhook end-to-end)
⚠ Needs a FRESH plan — if you already used step 5 on the current plan, click "Create Plan" (step 4) again first. Simulation always creates a new account, and can't reuse one that's already real. Requires your Flutterwave webhook URL to be saved in their dashboard (Settings → Webhooks) — no simulation reaches us without that.
7. Admin Records a Savings Payment (manual path — always works)
The real, correct flow: this stands in for a member paying into their own bank virtual account, with admin confirming the transfer landed — same interim step as the original manual process, no Zil/wallet involved at all.

9. Guarantor Confirms

11. Check Borrower's Own Status View
